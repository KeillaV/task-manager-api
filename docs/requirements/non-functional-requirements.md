# Requisitos Não Funcionais

## 1. Introdução
Este documento descreve os requisitos não funcionais do sistema Task Manager, uma aplicação pessoal para gerenciamento de tarefas.

## 2. Requisitos Funcionais

### RNF-001 - Desenvolvimento em Java 25
**Descrição**
O sistema deve ser desenvolvido em Java, com framework Spring

### RNF-002 - Aplicação de Java Efetivo
**Descrição**
No desenvolvimento, devem ser aplicados os conhecimentos obtidos no livro Java Efetivo

### RNF-003 - Persistência relacional
**Descrição**
Para banco de dados, deve ser utilizada persistência relacional com Postgresql
